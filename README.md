# TasteBite - Responsive Restaurant Website

## Description

TasteBite is a modern responsive restaurant website built as part of
the DecodeLabs Frontend Development Internship - Project 2.

The project demonstrates responsive web design using HTML5 and CSS3,
including responsive navigation, CSS media queries, Flexbox, Grid,
proper spacing, and layouts that adapt to desktop, tablet, and mobile
screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive navigation
- Mobile hamburger menu
- Responsive hero section
- Responsive food menu cards
- Customer reviews section
- Reservation/contact form
- Responsive footer
- Desktop, tablet and mobile layouts

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

No server or installation is required.
